Parecido com a playlist de Django, essa playlist de Next.js ensinou a como fazer o front-end de uma aplicação Next.JS para uma lista de tarefas.
Foram apresentados alguns elementos do Next.js como "use client", sistema de roteamento, estrutura das pastas, chamadas de API básica, mas uma boa parte do conteúdo foi focada em React, como o uso do useState, componentes, props e estados.

Meu fluxo de pensamento para a construção de novas aplicações seriam algo tipo:

1. Análise da API, entender o que o backend fornece para saber quais informações podem ser exibidas
2. Imaginar a interface como se ela estivesse pronta, e separar ela em partes menores
3. Identificar quais dessas partes menores poderiam ser transformadas em componentes
4. Construir os componentes, implementar props para maior flexibiliadade e reutilização
5. Montar a interface utilizando os componentesd, passando props mockadas para testes
6. Substituir as props mockadas por chamadas reais para a API
